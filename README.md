# Library System
A Spring Boot application for managing a library, including books, borrowers, and borrowing transactions.

## Usage
1. Access the H2 database console at **http://localhost:8080/h2-console** (JDBC URL: jdbc:h2:file:./librarydb, Username: library, Password: 123456).
2. Test the REST endpoints at **http://localhost:8080/swagger-ui.html**.

## Configuration

Configuration settings for this project are located in `src/main/resources/application.properties`.
